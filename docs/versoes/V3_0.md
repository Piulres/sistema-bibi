# ServiceOS v3.0 — Mobile app shell (PWA + WebView)

Linha **v3.0.x** — experiência de aplicativo no celular (iPhone/Android) sem
interromper o pacote **v2.4.x** em produção.

| Campo | Valor |
|-------|-------|
| **Versão alvo** | `3.0.0` *(em desenvolvimento — ainda não publicada)* |
| **Branch de trabalho** | `cursor/serviceos-v3-*` |
| **Base de integração** | PR → **`dev`** (nunca direto em `main`) |
| **Produção enquanto isso** | permanece **v2.4.0** — [`RELEASES.md`](RELEASES.md) |
| **Foco** | PWA standalone + caminho Capacitor (WKWebView) |

---

## Princípio de isolamento

Features paralelas (v2.x / CEDIG / hotfixes) **não devem** interferir neste fluxo:

1. **Não** alterar `PLATFORM.release` / `package.json` `version` para `3.0.0` até fechar o pacote.
2. Código v3.0 é **aditivo** (manifest, ícones, metas Apple, docs, pasta `mobile/`).
3. Branches `cursor/serviceos-v3-*` concentram o trabalho; outras features usam branches próprias.
4. Merge em `dev` só com mudanças não-breaking para a demo v2.4.

- [ ] Splash + ícone nativos
- [ ] TestFlight / distribuição interna

### Fora de escopo v3.0.0

- Redesign dos portais
- Novo modelo de dados
- Deploy Netlify automático
- Bump de versão em produção antes do fechamento do pacote

## Como testar (iPhone)

1. `npm run dev` → abrir a URL no **Safari**
2. Compartilhar → **Adicionar à Tela de Início**
3. Abrir o ícone — deve abrir sem barra do Safari (`standalone`)
4. Guia in-app: `/instalar`
