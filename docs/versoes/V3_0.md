## Princípio de isolamento

Features paralelas (v2.x / CEDIG / hotfixes) **não devem** interferir neste fluxo:

1. **Não** alterar `PLATFORM.release` / `package.json` `version` para `3.0.0` até fechar o pacote.
2. Código v3.0 é **aditivo** (manifest, ícones, metas Apple, docs, pasta `mobile/`).
3. Branches `cursor/serviceos-v3-*` concentram o trabalho; outras features usam branches próprias.
4. Merge em `dev` só com mudanças não-breaking para a demo v2.6.

## Gate Netlify (antes de publicar)

Validação **sem deploy** — o mesmo pipeline do CI local:

```bash
npm run pre-release
# inclui: lint → docs → openapi → db → tests → netlify:build → smoke-netlify-pwa
```

O passo `smoke-netlify-pwa` sobe `next start` no artefato de build e confere:

| Check | Esperado |
|-------|----------|
| `/`, `/instalar`, `/login`, `/interno/login` | 200 HTML |
| `/manifest.webmanifest` | `display: standalone` + ícones |
| `/icons/icon-192.png`, `512`, `apple-touch-icon` | 200 PNG |
| Metas Apple + `rel=manifest` na home | presentes |
| Chunk `/_next/static/*.css` | 200 |

Só depois: merge `dev` → `main` → `npx netlify deploy --prod` (humano; **não** `--no-build`).

## Como testar (iPhone)

1. `npm run dev` → abrir a URL no **Safari**
2. Compartilhar → **Adicionar à Tela de Início**
3. Abrir o ícone — deve abrir sem barra do Safari (`standalone`)
4. Guia in-app: `/instalar`
